# 🎵 **Timbre: Customized School Bell System**

**Timbre** is the modern and efficient solution to transform the classic school bell into a fully customizable tool. This application allows schools to schedule specific songs or sounds to automatically play during class transitions, while also including options for **drills** and **emergencies**.

**Timbre** has already been successfully implemented in several schools, enhancing the environment and providing a more enjoyable experience for both students and staff.

---

## 🚀 **Project Description**

Traditional school bell systems can often feel monotonous and outdated. **Timbre** offers an innovative solution that allows schools to customize the melodies or songs that play during class changes.

In addition, it incorporates special features such as:

- **Drills**: Play specific sounds for evacuation practices or safety drills.  
- **Emergencies**: Quickly alert the entire institution in critical situations with preconfigured sounds.  

The application is user-friendly and configurable, adapting to the needs of any educational institution.

---

## 🛠️ **Technologies Used**

This project uses the following technologies and modules:

- **Electron**: The main framework for creating cross-platform desktop applications with web technologies.  
- **Toastify-js**: A lightweight library for visual notifications and alerts.  
- **Electronmon**: A tool for automatically reloading the application during development.  

---

## 📦 **Installation**

To run the application locally, follow these steps:

1. **Clone the repository**:  
   ```bash
   git clone https://github.com/ALVNF/Timbre.git
   cd timbre
   ```
2. **Install the necessary dependencies:**
    ```bash
    npm install
    ```
3. **Run the application:**
    ```bash
    npm start
    ```

---

## 📸 **Main Features**

- 🎶 **Custom Song Playback**: Configure any audio file to play during class changes.  
- ⏰ **Programmable Schedules**: Adjust the bell schedules according to the school's needs.  
- 🚨 **Drills and Emergencies**:  
   - Play specific sounds for evacuation drills.  
   - Activate emergency sounds quickly in critical situations.  
- 🔔 **Visual Notifications**: Generate alerts and visual messages using **Toastify-js**.
